# Landing Page

## Project Description

This project is a landing page created as part of **The Odin Project** curriculum. The goal of this project is to recreate a given design using HTML and CSS, with a strong focus on layout and styling.

The page is built from scratch based on a provided design reference, emphasizing proper structure, spacing, and alignment rather than functionality or interactivity.
